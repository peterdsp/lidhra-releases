This repository holds **nothing but the installers**. It exists so the downloads and the
in-app updater work; the source lives elsewhere and is not public.

### Get it

**[Download the latest release](https://github.com/peterdsp/lidhra-releases/releases/latest)**

| Platform | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `.dmg` |
| Windows | `.msi` or `.exe` |
| Linux | `.AppImage`, `.deb` or `.rpm` |
| iPhone and iPad | [App Store](https://apps.apple.com/app/lidhra/id6790952504) |

Every file is signed, and `.sig` files alongside them are what the built-in updater
checks before installing anything.

`latest.json` is the updater feed. Installed copies read it to find out whether there is
a newer version. It is not meant to be downloaded by hand.
